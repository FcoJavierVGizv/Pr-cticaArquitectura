Ejercicio 1: Variables y Consola de DevTools

Enunciado

Declara variables de varios tipos. Muestra el contenido en la consola junto con el tipo de dato. En este ejercicio utiliza console.log, console.error, console.info y console.debug.

Ejecución

Haz clic en el botón para mostrar los mensajes y tipos de datos en la consola del navegador.

Estado de la Salida

Abre las DevTools (F12) y pulsa el botón para ver la salida.
